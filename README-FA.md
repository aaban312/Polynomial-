# کارگاه نمودار — نسخهٔ ۲ (PWA)

برنامهٔ رایگان، مستقل و بدون وابستگی به CDN یا کتابخانه‌های خارجی، مناسب استفاده روی موبایل و دسکتاپ.

## نصب نسخهٔ جدید روی همان GitHub Pages قبلی

1. فایل ZIP را استخراج کن.
2. **تمام محتویات داخل پوشهٔ ZIP** (`index.html`, `app-v2.js`, `styles-v2.css`, `sw.js`, `manifest-v2.webmanifest`, پوشهٔ `icons`) را در ریشهٔ مخزن GitHub Pages قبلی‌ات (مثل `Polyn`) جایگزین/آپلود کن. خود پوشهٔ مادر را به‌صورت یک زیرپوشهٔ اضافه منتقل نکن.
3. تغییرات را Commit کن. سایت را از آدرس HTTPS قبلی باز کن و صفحه را یک بار مجدداً بارگذاری کن.
4. اگر PWA قبلی را نصب کرده‌ای، آن را باز کن، صفحه را تازه‌سازی کن و در صورت نیاز اپ را ببند و دوباره باز کن. برای جلوگیری از تداخل با فایل‌های Cache نسخهٔ قبلی، نام فایل‌های JavaScript و CSS این نسخه عمداً تغییر کرده است.
5. در Chrome اندروید از منوی سه‌نقطه «نصب برنامه» / «Add to Home Screen» را انتخاب کن. اگر مرورگر پیشنهاد نصب را نشان نداد، HTTPS و وجود فایل‌های Manifest و Service Worker را بررسی کن.

**توجه:** پروژه‌های ذخیره‌شده به همان نشانی/Origin و همان پروفایل مرورگر وابسته‌اند. اگر دامنه عوض شود، داده‌های محلی خودکار منتقل نمی‌شوند. قبل از تغییر دامنه، از تب «پروژه‌های من» نسخهٔ JSON بگیر.

## اجرای روی رایانه به‌صورت آفلاین

اگر Python روی رایانه نصب است، در پوشهٔ حاوی `index.html` اجرا کن:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کن. پس از نخستین بارگذاری موفق روی HTTPS یا localhost، Service Worker فایل‌های اصلی برنامه را برای اجرا بدون اینترنت ذخیره می‌کند.

## راهنمای سریع

- **اهرم‌ها:** در موبایل نمودار بالا ثابت می‌ماند و پنل اهرم‌ها پایین، مستقلاً اسکرول می‌شود. برای انتخاب نمودار روی نام رنگی آن بزن.
- **تابع جدید:** عبارت را بنویس یا از نمونه‌ها انتخاب کن، سپس «افزودن به نمودار».
- **چندجمله‌ای:** `2x+5`، `x^2-4x+3`، `x^5-x^3+2x`؛ هر ضریب یک اهرم دارد.
- **قدرمطلق:** `abs(2x-3)+1` یا `|x-2|`.
- **رادیکال:** `sqrt(x+1)` یا `√(x+1)` و `cbrt(x)`.
- **جزء صحیح:** `floor(x)`، `⌊x⌋`، `[x]`، و `frac(x)` برای بخش کسری؛ `ceil(x)` برای سقف.
- **گویا:** `1/(x-2)`.
- **نمایی و لگاریتمی:** `exp(x)`، `ln(x)`، `log(x)` (پایهٔ ۱۰) و `log(x,2)` (پایهٔ دلخواه).
- **مثلثاتی:** `sin(x)`، `cos(x)`، `tan(x)` و `cot(x)`؛ زاویه‌ها **رادیانی** هستند.
- **چندضابطه‌ای:** `if(x<0,-x,x)` (برای شرط یک نامعادله بنویس).
- **پارامتر آزاد:** `a*abs(x-b)+c`، `a*sqrt(x-b)+c` یا `a*sin(b*x)+c`. برای `a,b,c,d,h,k,m,n` اهرم ساخته می‌شود. اعداد عادی در توابع غیرچندجمله‌ای هم (به‌جز نماها) اهرم می‌گیرند.
- **نامعادلهٔ x:** `x^2-4<0`؛ قسمت‌های معتبر روی نمودار به شکل نوارهای عمودی نیمه‌شفاف رنگ می‌شوند.
- **نامعادلهٔ y:** `y>=x^2`؛ ناحیهٔ بالای/پایین منحنی به‌صورت نیمه‌شفاف رنگ می‌شود.
- **معادلهٔ ریشه‌یابی:** `abs(x-2)=3`؛ ریشه‌های تقریباً عددی در محدودهٔ قابل‌مشاهده مشخص می‌شوند. مرزهای < و <= از نظر رسم نوار مشترک‌اند و باز/بسته بودن مرز از نماد ورودی مشخص می‌شود.
- **تنظیمات:** بزرگ‌نمایی با +/− یا دو انگشت، جابه‌جایی با کشیدن نمودار، برازش خودکار با ⊡ و ذخیرهٔ تصویر PNG با ⇩.
- **پروژه‌های من:** ذخیرهٔ نام‌دار (در localStorage همان مرورگر)، باز کردن، حذف و نسخهٔ پشتیبان JSON؛ تغییرات پروژهٔ فعلی هم خودکار ذخیره می‌شود.
- **تم:** کلید «تاریک / روشن» در نوار بالا؛ انتخاب آخر در مرورگر باقی می‌ماند.

## محدودیت‌ها و نکات علمی

- این برنامه **ماشین‌حساب نمادین (CAS)** نیست. فقط نمودارهای عددی و نواحی نامعادله را به‌صورت نمونه‌برداری رسم می‌کند. ممکن است ریشه‌های مماسی، خیلی نزدیک، خارج از دید، یا رفتارهایی نزدیک مجانب‌ها با تقریب محدود نمایش داده شوند.
- استفاده از `y=...` برای رسم تابع، `y>=...`/`y<=...` برای ناحیهٔ دوبعدی و `f(x)>=g(x)` برای ناحیهٔ جواب روی محور x پشتیبانی می‌شود؛ نامعادلات ترکیبی/دستگاه معادلات و منحنی ضمنی دلخواه مانند `x^2+y^2=1` در این نسخه پیاده نشده‌اند.
- مقدار متغیرهای قابل تنظیم به بازهٔ ±۱۰ میلیون محدود است؛ درجات چندجمله‌ای دارای کنترل خودکار ضرایب ۰ تا ۵ هستند. عبارت‌های دیگر با توان‌های حقیقی هم در حد تعریف‌پذیری ریاضی رسم می‌شوند.
- جابه‌جایی و تقریب منحنی برای برخی توابع ناپیوسته (جزءصحیح و گویا) ممکن است به دلیل نمونه‌برداری ظاهری شبیه پله یا شکستگی ظریف داشته باشد.
- پاک کردن تاریخچه/داده‌های سایت یا استفاده از حالت ناشناس می‌تواند همهٔ پروژه‌های محلی را پاک کند. برای انتقال یا پشتیبان‌گیری از خروجی JSON استفاده کن.

## فایل‌ها

- `index.html` رابط برنامه
- `styles-v2.css` سبک‌ها و تم روشن/تاریک و ساختار دوپنلی موبایل
- `app-v2.js` تحلیل‌گر ایمن عبارت، رسم Canvas، اهرم‌ها، ذخیره‌سازی، تعامل
- `manifest-v2.webmanifest` مشخصات نصب PWA
- `sw.js` فایل‌های مورد نیاز برای کارکرد آفلاین
- `icons/` آیکون‌های برنامه

تمام کدها و دارایی‌ها محلی هستند؛ هیچ داده‌ای به سرور شخص ثالث ارسال نمی‌شود. برای نصب PWA از سرور HTTPS یا localhost استفاده کن.
